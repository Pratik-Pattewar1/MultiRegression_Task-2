## 📌 Project Overview

This project demonstrates the use of **Multiple Linear Regression** to predict house prices using multiple property-related features.

The model learns the relationship between house characteristics and their corresponding prices and then uses this relationship to predict the price of a new house.

The project follows a complete machine learning workflow, including:

- Dataset creation and inspection
- Exploratory data analysis
- Feature and target selection
- Train-test splitting
- Multiple Linear Regression model training
- Model evaluation
- Prediction of a new house price
- Actual vs. predicted visualization
- Residual analysis

---

## 🎯 Objective

The main objective of this project is to build a Multiple Linear Regression model that can predict **house prices in ₹ lakhs** using multiple input features.

### Input Features

- `Area_sqft` — Area of the house in square feet
- `Bedrooms` — Number of bedrooms
- `Bathrooms` — Number of bathrooms
- `Age_years` — Age of the house in years
- `Parking` — Number of parking spaces

### Target Variable

- `Price_lakhs` — House price in ₹ lakhs
